一、为什么会提示木马
------------------------------------------------------------
本程序没有联网、上传或记录数据功能。出现“木马”提示，通常是
安全软件对程序行为的启发式判断：

1. 程序会监听鼠标双击，用来判断是否点在 Chrome 标签页上。
2. 程序会模拟一次 Ctrl+W 按键，用来关闭当前标签页。
3. 程序没有购买数字签名证书，安全软件无法确认发布者。
4. 程序常驻系统托盘，还可以设置开机启动。
5. 文件比较新、使用人数少，云查杀容易给出高风险判断。

“全局鼠标监听 + 模拟按键 + 后台运行 + 无签名”正好也是部分木马
常见的行为组合，因此 360 或 Windows Defender 可能误报。提示名称
如 QVM、HEUR、Trojan.Generic 等，通常属于启发式检测。


二、放行前先核对文件
------------------------------------------------------------
为了防止文件在发送或下载过程中被替换，请先核对 SHA256。

1. 在该 EXE 所在文件夹的空白处，按住 Shift 并右键。
2. 选择“在终端中打开”或“在此处打开 PowerShell 窗口”。
3. 输入下面的命令并按回车：

Get-FileHash ".\双击关闭Chrome标签.exe" -Algorithm SHA256

4. 查看输出中的 Hash 是否为：

39E6DB5268DB6EA0412F330BD97B2493B5F42972968702BA95CF46B2A4078418

哈希完全一致：可以继续按下面的方法添加信任。
哈希不一致：不要运行或放行，请重新从原位置复制文件。


三、360 安全卫士放行方法
------------------------------------------------------------
如果文件已经被隔离：

1. 打开 360 安全卫士。
2. 点击“木马查杀”。
3. 找到“恢复区”或“隔离区”。
4. 找到“双击关闭Chrome标签.exe”。
5. 选择“恢复”，再选择“添加信任”或“恢复并信任”。
6. 重新运行 EXE。

如果弹窗正在拦截：

1. 点击弹窗中的“查看详情”或“更多”。
2. 选择“添加信任”或“允许程序运行”。
3. 只信任“双击关闭Chrome标签.exe”这一个文件。

如果找不到恢复区，也可以手动添加信任：

1. 打开 360 安全卫士的“设置”。
2. 查找“信任区”或“文件信任”。
3. 点击“添加文件”。
4. 只选择“双击关闭Chrome标签.exe”。
5. 不要添加整个磁盘或整个下载目录。

如果仍然被拦截，可以在 360 的“查杀记录”或“恢复区”中找到
该文件，使用“误报反馈”提交。不同版本的按钮名称可能略有不同。


四、Windows 安全中心放行方法
------------------------------------------------------------
如果文件已经被隔离：

1. 打开“Windows 安全中心”。
2. 点击“病毒和威胁防护”。
3. 点击“保护历史记录”。
4. 找到被拦截的“双击关闭Chrome标签.exe”。
5. 点击“操作”，选择“允许在设备上”或“还原”。

如果文件没有被隔离，直接添加排除项：

1. 打开“Windows 安全中心”。
2. 点击“病毒和威胁防护”。
3. 点击“病毒和威胁防护设置”下的“管理设置”。
4. 找到“排除项”，点击“添加或删除排除项”。
5. 点击“添加排除项”，选择“文件”。
6. 只选择“双击关闭Chrome标签.exe”这一个文件。
7. 确认后重新运行程序。

Windows 可能要求管理员确认，这是正常现象。


五、安全提醒
------------------------------------------------------------
1. 只放行“双击关闭Chrome标签.exe”这一个文件。
2. 不要关闭整个杀毒软件。
3. 不要排除整个磁盘、整个下载目录或整个用户目录。
4. 哈希不一致时不要放行。
5. 如果不想添加任何杀毒软件信任，可以改用 Chrome 扩展版本；
   扩展版本不需要 EXE，但只能在扩展侧栏或网页空白处双击关闭。

七、常见问题
------------------------------------------------------------
问：换一个 AI 模型能解决报毒吗？
答：不能。报毒来自安全软件对 EXE 行为的判断，与生成代码的模型无关。

问：程序会不会记录我的鼠标操作？
答：不会。程序只在内存中判断鼠标是否双击了 Chrome 标签，不保存、
不上传鼠标记录。

问：为什么程序需要模拟 Ctrl+W？
答：Chrome 没有向普通程序开放“关闭指定标签”的接口，因此程序先
确认双击位置是标签页，再向 Chrome 发送 Ctrl+W。

问：兼容模式是什么？
答：默认不要开启。只有某些 Chrome 版本无法识别标签时，才在托盘
菜单中临时开启兼容模式。
