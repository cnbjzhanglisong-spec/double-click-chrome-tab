# 双击关闭 Chrome 标签

本项目提供两种实现方式：

- **独立 EXE（推荐）**：直接监听 Chrome 原生标签栏，双击标签即可关闭。
- **Chrome 扩展**：受浏览器限制，只能在扩展侧栏或网页空白处双击关闭。

## 推荐：独立 EXE 版本

文件位置：

`dist\v1.1.8\双击关闭Chrome标签.exe`

直接双击运行，无需安装。启动后会显示主窗口，同时常驻 Windows 系统托盘。

### 使用方法

1. 运行 `双击关闭Chrome标签.exe`，主窗口会显示使用方法和注意事项。
2. 双击 Chrome 顶部任意原生标签页即可关闭。
3. 点击主窗口关闭按钮不会退出，只会隐藏到系统托盘。
4. 单击或双击系统托盘中的程序图标，可重新打开主窗口。
5. 主窗口底部可勾选“开机自启动”，并与托盘菜单双向同步。
6. 右键托盘图标可选择暂停、兼容模式、开机启动或退出。
7. 请勿同时运行多个版本；如有旧版在托盘运行，请先右键旧版图标退出。
### 实现特点

- 通过 UI Automation 精确识别 Chrome 的 `TabItem`，不会把网页、地址栏或工具栏当作标签。
- 会校验前后两次点击都发生在 Chrome 标签上，避免关闭按钮消失后误关相邻标签。
- 默认无需管理员权限，不联网，不记录鼠标历史，不上传数据。
- 如果 Chrome 以管理员身份运行，本程序也需要使用相同权限运行。

### 兼容模式

默认不需要开启。如果某个 Chrome 版本无法识别标签，可右键托盘图标，勾选“兼容模式”。兼容模式会把窗口顶部标签栏区域作为备用判断范围。

### 系统要求

- Windows 10 或 Windows 11。
- .NET Framework 4.8（Windows 10/11 通常已自带）。
- 程序未做数字签名，首次运行时 Windows SmartScreen 可能显示“未知发布者”。

360 安全卫士和 Windows 安全中心的详细误报说明与放行步骤见：`dist\v1.1.8\杀毒软件误报与放行说明.pdf`。

## Chrome 扩展版本

扩展安装包：

`dist\双击关标签-v1.2.0.zip`

扩展版本的两种双击方式：

1. 点击扩展图标打开侧栏，在标签列表中双击关闭。
2. 在普通网页背景或布局空白处双击，关闭当前标签。

### 扩展功能

- 侧栏中单击切换标签，双击关闭标签。
- 支持搜索标签页、多窗口分组、固定标签标识。
- 网页空白双击可在侧栏底部关闭。
- 新开、关闭、移动或切换标签时自动同步。
- 不联网，不上传浏览数据。

### 为什么扩展不能直接双击原生标签栏

Chrome 扩展 API 不提供原生标签栏上的鼠标点击或双击事件，因此普通扩展无法拦截标签栏双击。需要原生标签栏双击时，请使用独立 EXE 版本。

### 扩展安装

1. 在 Chrome 地址栏打开 `chrome://extensions/`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目文件夹：`D:\codex工作区\谷歌标签双击关闭`。
5. 将“双击关标签”固定到工具栏，点击图标即可打开侧栏。

也可以解压 `dist/双击关标签-v1.2.0.zip`，然后加载解压后的文件夹。

### 将侧边栏移到左侧

Chrome 原生侧边栏的位置属于浏览器设置，扩展无法单独修改。可在插件底部点击“去设置”，或手动操作：

1. 点击 Chrome 右上角的“更多”菜单。
2. 打开“设置” > “外观”。
3. 在“侧边栏”下选择“左侧”。

该设置会影响 Chrome 的整个原生侧边栏，而不是只影响本扩展。

### 扩展使用

- **侧栏**：单击切换标签；双击关闭；按 `Delete` 或 `Backspace` 关闭当前聚焦项。
- **搜索**：按 `/` 聚焦搜索框，按 `Esc` 清空并退出搜索。
- **网页空白双击**：默认开启。双击背景或布局空白处触发；文字、链接、按钮、输入框、图片、媒体和常见交互区域不会误触发。
- **固定标签**：可以关闭，但双击前请确认。

### 扩展权限

- `tabs`：读取标签页标题、网址和窗口信息，并关闭或切换标签。
- `storage`：保存“网页空白处双击关闭”的开关状态。
- `sidePanel`：在 Chrome 侧栏中显示标签列表。
- `scripting`：扩展安装或刷新后，向已打开的网页注入双击检测。
- 网页内容脚本只识别空白处双击，不采集、保存或发送网页数据。

### 扩展支持范围

- Chrome 114 及以上版本。
- 网页空白双击支持 `http://`、`https://` 和已授权的 `file://` 页面。
- Chrome 内部页面和 Chrome 应用商店页面受浏览器限制；这些页面仍可在扩展侧栏中双击关闭。

## 文件结构

```text
manifest.json             Chrome 扩展配置
background.js             扩展后台 Service Worker
sidepanel.html            扩展侧栏界面
sidepanel.css             侧栏样式
sidepanel.js              标签列表与交互逻辑
content.js                网页空白处双击检测
native/                   独立 EXE 的 C# 源码、主窗口、清单与图标
icons/                    扩展和 EXE 图标
tools/                    构建、图标生成与打包脚本
dist/                     可执行文件和发布压缩包
```

## 开发与验证

```powershell
node --check background.js
node --check content.js
node --check sidepanel.js
.\tools\generate-icons.ps1
.\tools\package-extension.ps1
.\tools\build-exe.ps1
```

修改扩展代码后，在 `chrome://extensions/` 中点击扩展卡片上的刷新按钮。扩展会尝试自动向已打开网页注入新版双击检测；如果页面仍未生效，请刷新该网页一次。
